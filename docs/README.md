# Design notes, contracts, and evidence

Supporting documentation for development decisions, data contracts, integrations, and evaluations. Start with [developer notes](../README_DEV.md) for setup and [the codebase guide](../CODEBASE.md) for source navigation.

- `birdnet-3-*.md`: upgrade, development, and validation notes for the BirdNET integration.
- `rainfall-contract.md` and `preflight-buzz.md`: behavior contracts and limitations.
- `wingbeat-*.md`: detector research, sources, audits, and evaluation context.
- [evaluations](evaluations/README.md): dated reports and supporting artifacts.
- [reference](reference/README.md): external/reference formats and taxonomy material.
- [archive](archive/README.md): historical development records.

Dated documents describe their recorded state; current executable behavior lives under `src`, with regression coverage in `tests`. Embedded scripts and result files in historical evaluations are preserved evidence rather than maintained application modules.
