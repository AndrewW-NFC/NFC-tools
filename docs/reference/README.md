# Reference material

External formats, region lists, taxonomy lookups, and reviewer-filter notes used to interpret exports and metadata. This includes eBird import examples, geographic codes, and Nighthawk family/species mapping notes.

Application consumers are `ebird_export.py`, `ebird_locations.py`, and `ebird_rarity.py`. The packaged runtime taxonomy is in [src/nfc_tools/data](../../src/nfc_tools/data/README.md); these reference documents are supporting material, not all installed runtime inputs. Preserve source formats and attribution when updating them.
