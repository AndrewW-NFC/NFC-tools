# Evaluation reports and artifacts

Dated wingbeat experiments and validation results. Standalone Markdown reports summarize changes; named subfolders hold reports, feature tables, scripts, and other supporting artifacts for a particular evaluation. Read a subfolder's README or report before interpreting its data.

Maintained evaluation commands live in [scripts](../../scripts/README.md) and [tools](../../tools/README.md); production screening lives in [analyzers](../../src/nfc_tools/analyzers/README.md). These snapshots may refer to external recordings or earlier detector versions. Their datasets and embedded scripts are retained as evidence, not rewritten as current source documentation.
