# Automatically save all Settings changes

Requested and explicitly approved for immediate implementation on November 17,
2026, as an exception to the project hold.

The November 16 session recorded with the explicitly configured MacBook Air
Microphone while External Microphone was available. Logs cannot establish whether
the user's external-mic choice went unsaved or was later overwritten.

Settings now save automatically by section, with persistent and local feedback,
ordered requests, validation, and retry after failures. Microphone status updates
after saving. The map, folder picker, analyzer checkboxes, and reviewer CSV flow
use the same mechanism. No repeated Save buttons are required; a full-form Save
fallback remains only when JavaScript is disabled.

Updated README.md, README_DEV.md, and README_WINGBEATS.md. Automated validation
covers software behavior; no field-performance claim is made.
