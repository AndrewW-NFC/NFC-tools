# Research archive

This tree preserves research handoffs rather than the maintained application. [archive](archive/README.md) contains dated snapshots and their original instructions, feature dictionaries, and checksums.

Current research commands live in [tools](../tools/README.md), current detector code in [analyzers](../src/nfc_tools/analyzers/README.md), and evaluation reports in [docs/evaluations](../docs/evaluations/README.md). Original recordings and large collection assets may live outside Git.
