Your first listening session

The batch contains about eight minutes of audio. Allow extra time to replay and mark passages. Headphones may help with faint sounds.

  1. Listen before revealing the source notes. No detector predictions are shown.
  2. Choose present, none heard, or uncertain. For present sounds, mark each passage with start/end times.
  3. Use “Complete” after hearing the whole recording. Save partial listening as “In progress”; use “Needs another listen” for uncertainty.
  4. Save & next. You can return to any recording; earlier saved revisions remain recoverable.

The green band tracks played portions, not your judgment. Skipped sections are not counted. Slower playback helps locate sounds but changes their perceived rhythm; check at 1× before deciding.

Annotations, revision history and JSON backups are saved on the T7. CSV and full JSON exports are available above.
